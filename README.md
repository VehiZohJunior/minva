# MinVa — Gestion d'Organisations

Site vitrine, console admin des organisations clientes et sites publics de chaque organisation.

- `index.html` : site vitrine
- `admin.html` : console admin (3 administrateurs par organisation)
- `site.html` + `404.html` : site public de chaque organisation (`/minva/<lien>`)
- `supabase/` : schéma de la base de données et fonctions serveur
